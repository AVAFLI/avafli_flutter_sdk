# avafli_example

Example app demonstrating the Avafli Engagement SDK (`avafli_sdk`) integration:
configure with a demo key, attach `Avafli.navigatorKey`, and the experience
auto-opens once per day. Includes demo-only affordances to reset the
auto-open state and to exercise the GDPR erasure path.

Run it from this directory:

```bash
flutter run
```
